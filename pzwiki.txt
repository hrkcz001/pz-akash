There are a total of 4 files that make your server work, they can all be found at:

* Windows: <code>%USERPROFILE%\Zomboid\server</code>
* Linux: <code>$HOME/Zomboid/Server</code>

Inside, there are the following files:

* <code>servertest.ini</code>
* <code>servertest_SandboxVars.lua</code>
* <code>servertest_spawnpoints.lua</code>
* <code>servertest_spawnregions.lua</code>

== Server Settings File (servertest.ini) ==
This file contains the non-gameplay related settings for the server, including the settings for configuring mods.

===== AntiCheat =====
These settings control the Anti-cheat functionality of the server.

The avilable settings are as follows.

# Ban - Instantly ban anyone violating the anti-cheat rule
# Kick - Instantly kick anyone violating the anti-cheat rule
# Log - Log violations of the rule in the server logs
# Disable - Do nothing when a rule is violated

== Spawn Points Lua (servertest_spawnpoints.lua) ==
<syntaxhighlight lang="lua">
function SpawnPoints()
	return {
		unemployed = {
			{ worldX = 40, worldY = 22, posX = 67, posY = 201 }
		}
	}
end

</syntaxhighlight>This file is used to add potential spawn points to the map for a given profession without requiring a Spawn Region in that area.

Spawn Points can be added for a given occupation, the details of which can be found in the list of occupations [[Occupation|here]]

To create a new spawn point for a given profession, add a new record within the return block of the SpawnPoints() function in the format below.<syntaxhighlight lang="lua">
blacksmith = {
	{ worldX = 40, worldY = 22, posX = 67, posY = 201 },
	{ worldX = 40, worldY = 22, posX = 10031, posY = 4432 }
}
